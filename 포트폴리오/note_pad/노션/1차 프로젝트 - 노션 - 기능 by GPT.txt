1. 히스토리 조회 및 자동 갱신 — HST-001
기능 설명

저장된 히스토리를 조회하고 사용자의 권한에 따라 조회 가능한 데이터를 제공하며, 새로운 히스토리가 발생하면 실시간으로 목록을 갱신하도록 구현.

-----------------------------------------------------------------------
동작 흐름
페이지 접속
 ↓
히스토리 목록 요청
 ↓
권한 확인
 ↓
히스토리 데이터 조회
 ↓
최신순 정렬
 ↓
화면 출력
      ↑
      │
새로운 히스토리 발생
      │
     SSE
      │
목록 자동 갱신

-----------------------------------------------------------------------
사용 기술
Flask
Python
JSON
SSE
JavaScript

==========================================================================================
2. 탐지 히스토리 관리 — HST-002
기능 설명

AI 영상 분석 과정에서 발생한 탐지 이벤트를 저장하고, 탐지 대상과 발생 시간 및 위치 등의 정보를 조회할 수 있도록 구현.

-----------------------------------------------------------------------
데이터 흐름
AI 탐지
 ↓
탐지 이벤트 생성
 ↓
이벤트 데이터 저장
 ↓
히스토리 조회
 ↓
탐지 정보 + 캡처 이미지 출력

==========================================================================================
3. 히스토리 선택 및 읽음 처리 — HST-003
기능 설명

사용자가 특정 히스토리를 선택하거나 여러 히스토리를 일괄 선택하여 읽음 처리할 수 있도록 구현.

-----------------------------------------------------------------------
동작 흐름
히스토리 선택
 ↓
개별 / 일괄 선택
 ↓
읽음 처리
 ↓
상태 변경
 ↓
리드 히스토리 저장

==========================================================================================
4. 히스토리 목록 및 내보내기 — HST-004
기능 설명

히스토리를 테이블 형태로 제공하고 페이지네이션을 통해 데이터를 분할하여 조회할 수 있도록 구현. 또한 조회한 히스토리를 파일로 내보낼 수 있도록 구현.

-----------------------------------------------------------------------
화면 구조
┌──────────────────────────────────────────────┐
│ 검색 / 필터                                  │
├──────────────────────────────────────────────┤
│ Event ID │ 시간 │ 대상 ID │ 위치 │ 읽음 여부 │
├──────────────────────────────────────────────┤
│ ...                                          │
│ ...                                          │
├──────────────────────────────────────────────┤
│ [1] [2] [3] [4]              [Excel] [JSON] │
└──────────────────────────────────────────────┘

==========================================================================================
5. 히스토리 검색 — HST-005
기능 설명

이벤트 ID, 대상 ID 및 검색어를 이용하여 원하는 히스토리를 검색할 수 있도록 구현.


-----------------------------------------------------------------------
동작 흐름
검색어 입력
 ↓
검색 조건 확인
 ↓
히스토리 검색
 ↓
검색 결과 출력
 ↓
결과 없음
 → 안내 메시지 출력

==========================================================================================
6. 히스토리 필터링 및 정렬 — HST-006
기능 설명

히스토리의 상태, 탐지 대상, 발생 기간 등의 조건을 이용하여 원하는 데이터를 필터링하고 정렬할 수 있도록 구현.

-----------------------------------------------------------------------
처리 구조
검색 조건
   +
필터 조건
   +
정렬 조건
   ↓
히스토리 데이터 처리
   ↓
페이지네이션
   ↓
결과 출력

==========================================================================================
