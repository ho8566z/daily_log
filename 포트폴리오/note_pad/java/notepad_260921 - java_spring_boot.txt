## ResponseEntity 란?

- Spring에서 HTTP 응답 전체(상태 코드, 헤더, 바디)를 세밀하게 제어할 수 있게 해주는 클래스이다.
- 컨트롤러 메서드의 반환 타입으로 주로 사용된다.

#### ResponseEntity의 주요 특징

- HTTP 상태 코드를 직접 지정 가능하다.(200, 201, 404, 500 등)
응답 헤더를 커스텀으로 추가 가능하다.
- 응답 바디에 원하는 데이터를 담을 수 있다.

## saveAndFlush 란?

- Spring Data JPA의 JpaRepository가 제공하는 메서드로, 엔티티를 저장하면서 즉시 DB에 반영(flush)까지 수행한다.

#### save()와의 차이

- save()
    - 영속성 컨텍스트(1차 캐시)에 엔티티를 저장한다.
    - 실제 DB에 쿼리가 나가는 시점은 트랜잭션이 커밋되거나 flush가 일어날 때이다.(보통 트랜잭션 종료 시점)
- saveAndFlush()
    - 저장과 동시에 즉시 flush()를 호출해서 바로 DB에 SQL을 실행시킨다.

```java
package com.office.calendaradmin.user;

import lombok.RequiredArgsConstructor;
import lombok.extern.slf4j.Slf4j;
import org.springframework.http.ResponseEntity;
import org.springframework.stereotype.Controller;
import org.springframework.web.bind.annotation.*;

import java.util.Map;

@Slf4j
@Controller
@RequestMapping("/user")
@RequiredArgsConstructor
public class UserController {

final private UserService userService;

// 사용자 목록 화면(/user/list)
@GetMapping("/list")
public String list() {
    log.info("list()");

    String nextPage = "user/list";

    return nextPage;

}

// 사용자 목록 조회(/user/users)
@GetMapping("/users")
public ResponseEntity<Map<String, Object>> users() {
    log.info("users()");

    Map<String, Object> resultMap = userService.users();

    return ResponseEntity.ok(resultMap);

}

// 사용자 권한 변경(/user/${userNo}/auth)
@PutMapping("{userNo}/auth")
public ResponseEntity<Map<String, Object>> updateUserAuthority(
        @PathVariable int userNo,
        @RequestBody Map<String, Integer> request
) {
    log.info("updateUserAuthority()");

    if (request.get("authorityNo") == null) {
        return ResponseEntity.badRequest()
                .body(Map.of("result", 0));
    }

    Map<String, Object> resultMap =
            userService.updateUserAuthority(userNo, request.get("authorityNo"));

    return ResponseEntity.ok(resultMap);

}
}
```

#### [ UserService ]

```java
package com.office.calendaradmin.user;

import com.office.calendaradmin.user.jpa.UserAuthorityEntity;
import com.office.calendaradmin.user.jpa.UserEntity;
import com.office.calendaradmin.user.jpa.UserRepository;
import lombok.RequiredArgsConstructor;
import lombok.extern.slf4j.Slf4j;
import org.springframework.stereotype.Service;
import org.springframework.transaction.annotation.Transactional;

import java.util.HashMap;
import java.util.List;
import java.util.Map;
import java.util.Optional;
import java.util.stream.Collectors;

@Slf4j
@Service
@RequiredArgsConstructor
public class UserService {

final public static int UPDATE_USER_AUTHORITY_SUCCESS   = 1;
final public static int UPDATE_USER_AUTHORITY_FAIL      = 0;

final private UserRepository userRepository;

public Map<String, Object> users() {
    log.info("users()");

    Map<String, Object> resultMap = new HashMap<>();

    List<UserEntity> userEntities = userRepository.findAll();
    List<UserDto> users = userEntities.stream()
            .map(UserEntity::toDto)
            .collect(Collectors.toList());

    log.info("users: {}", users);

    resultMap.put("users", users);

    return resultMap;

}

@Transactional
public Map<String, Object> updateUserAuthority(int userNo, Integer authorityNo) {
    log.info("updateUserAuthority()");

    Map<String, Object> resultMap = new HashMap<>();

    Optional<UserEntity> optionalUser = userRepository.findById(userNo);
    if (optionalUser.isPresent()) {
        UserEntity userEntity = optionalUser.get();

        Byte targetAuthorityNo = 1;
        if (authorityNo == 2)
            targetAuthorityNo = 2;

        userEntity.setAuthorityEntity(UserAuthorityEntity.builder()
                .authNo(targetAuthorityNo)
                .build());

        userRepository.saveAndFlush(userEntity);
        resultMap.put("resultMap", UPDATE_USER_AUTHORITY_SUCCESS);
        resultMap.put("mod_date", userEntity.toDto().getMod_date());

    } else {
        resultMap.put("resultMap", UPDATE_USER_AUTHORITY_FAIL);

    }
    return resultMap;
}
}
```

## Map.of("result", 0); 이란?

- 불변(immutable) Map을 간편하게 생성하는 정적 팩토리 메서드이다.

#### Map.of("result", 0)의 **특징**

- key-value 쌍을 인자로 나열한다.
    - Map.of(k1, v1, k2, v2, ...) (최대 10쌍까지 지원한다.)
- 반환된 Map은 수정 불가하다.
    - (불변) — put(), remove() 호출 시 UnsupportedOperationException가 발생한다.
- null key/value의 사용을 불허한다.
    - (NullPointerException이 발생한다.)
- 주로 컨트롤러에서 간단한 JSON 응답을 만들 때 사용한다.

## ResponseEntity.badRequest() 란?

- HTTP 상태 코드 400 Bad Request로 응답을 만드는 정적 편의 메서드이다.

#### 언제 사용하는지?

- 클라이언트가 잘못된 요청(파라미터 누락, 형식 오류, 유효성 검증 실패 등)을 보냈을 때
- 서버 내부 문제가 아니라 요청 자체가 잘못됐음을 명확히 알릴 때

## Spring Security 인가(Authorization) 설정 이란?

- 인증(Authentication)이 "누구인지 확인"하는 것이라면, 인가(Authorization)는 "이 사용자가 이 자원에 접근할 권한이 있는지 확인"하는 것입니다.
- Spring Security에서는 주로 SecurityFilterChain을 통해 설정한다.

#### 핵심 개념

| 메서드 | 의미 |
| --- | --- |
| permitAll() | 누구나 접근 가능 |
| authenticated() | 로그인만 하면 접근 가능 |
| hasRole("ADMIN") | 특정 권한(ROLE_ADMIN)을 가진 사용자만 접근 가능 |
| hasAnyRole("A", "B") | 여러 권한 중 하나라도 있으면 접근 가능 |
| denyAll() | 모두 차단 |
