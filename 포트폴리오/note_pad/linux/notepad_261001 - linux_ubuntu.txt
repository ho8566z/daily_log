#### JPA Entity에서 DB 테이블의 기본 키(PK)를 자동으로 생성하도록 설정하는 코드

```java
@Id
@GeneratedValue(strategy = GenerationType.IDENTITY)
private Long id;
```

| 코드 | 의미 |  |
| --- | --- | --- |
| @Id | 이 필드를 기본 키(PK) 로 지정 |  |
| @GeneratedValue | 기본 키 값을 자동으로 생성하도록 설정 |  |
| GenerationType.IDENTITY | DB의 AUTO_INCREMENT 기능을 사용해서 번호를 자동 생성 |  |
| private Long id | 생성되는 기본 키 값을 저장하는 id 변수 |  |

#### PUT은 왜 항상 값을 전부 다시 보내야 하는지?

- 리소스 전체를 새로운 상태로 교체하기 때문이다.
- 현재의 Products 데이터

```json
{
  "id": 6,
  "name": "모션 데스크",
  "price": 400000,
  "stock": 0,
  "description": "상하 틸트 기능",
  "soldOut": true,
  "createdAt": "2026-10-01T16:46:06.924736"
}
```

- price를 PUT으로 수정한다면

```
http://

PUT /api/products/6
```

```json
{
  "name": "모션 데스크",
  "price": 450000,
  "stock": 0,
  "description": "상하 틸트 기능",
  "soldOut": true
}
```

- PUT으로 실행하는 “/api/products/6”은 id가 6번인 products의 전체 정보를 새로운 내용으로 교체한다.
- 때문에 id, createdAt 같은 서버가 관리하는 값은 PUT 요청에서 보통 클라이언트가 보내지 않도록 설계한다.

#### 삭제의 종류

| 구분 | 차이점 | 장점 | 단점 |
| --- | --- | --- | --- |
| 물리 삭제(Hard Delete) | DB에서 해당 데이터를 실제로 삭제한다. | 구조가 단순하고 불필요한 데이터가 남지 않는다. | 삭제한 데이터를 복구하기 어렵다. |
| 논리 삭제(Soft Delete) | 데이터를 삭제하지 않고 deleted 같은 컬럼을 true로 변경하여 삭제된 것으로 처리한다. | 실수로 삭제해도 복구할 수 있고, 삭제 이력을 유지할 수 있다. | 조회할 때 삭제된 데이터를 제외하는 조건이 필요하고, 데이터가 계속 DB에 남는다. |

#### LIKE 검색 이란?

- 문자열이 특정 패턴과 일치하는 데이터를 찾는 SQL 검색 방법이다.
- 특히 검색어가 포함되어 있는 데이터를 찾을 때 많이 사용한다.

```sql
SELECT *
FROM products
WHERE name LIKE '%데스크%';
```

- name에 "모션"라는 문자열이 포함된 products를 조회한다.

#### %의 의미

| 패턴 | 의미 | 예시 |
| --- | --- | --- |
| LIKE '모션' | 정확히 ‘모션’과 일치 | 모션 |
| LIKE '모션%' | ‘모션’로 시작 | 모션 데스크, 모션 테이블 |
| LIKE '%모션' | ‘모션’로 끝남 | 스마트 모션 |
| LIKE '%모션%' | ‘모션’가 포함됨 | 모션 데스크, 스마트 모션 |

| --- | --- | --- | --- |

## utf-8(Unicode Transformation Format - 8-bit) 이란?

- 문자(한글, 영어, 숫자, 특수문자 등)를 컴퓨터가 저장하고 전송할 수 있는 바이트 형태로 변환하는 문자 인코딩 방식이다.

```
"ABC"
    ↓ UTF-8 인코딩
41 42 43
```

```
"가"
    ↓ UTF-8 인코딩
EA B0 80
```

#### 왜 UTF-8을 사용하는지?

- 한글이나 영어처럼 다양한 문자를 하나의 인코딩 방식으로 처리할 수 있기 때문에 개발할 때 다음처럼 자주 볼 수 있다.

```
Content-Type: application/json; charset=UTF-8
```

- JSON 데이터를 UTF-8 방식으로 인코딩한다는 의미이다.

## hostname -I 란?

- 현재 Linux/Ubuntu 컴퓨터가 가지고 있는 IP 주소를 확인하는 명령어이다.

```
hostname -I
```

```
172.21.112.234 172.17.0.1
```

| hostname | 컴퓨터의 호스트 이름과 관련된 정보를 확인하는 명령이다. |  |
| --- | --- | --- |
| -I | 컴퓨터의 IP 주소(들)를 출력한다. |  |

#### hostname -i와 차이

- 대문자 I와 소문자 i는 다르다.
- 컴퓨터에 할당된 IP 주소들을 확인한다.

```
hostname-I
```

- 호스트 이름을 기준으로 IP 주소를 확인한다.

```
hostname-i
```
