- PowerShell에서는 Window 명령을 입력하고, Ubuntu에서는 Linux 명령을 입력한다.
- 실제 작업은 Ubuntu에서 진행하지만, PowerShell에서 WSDML 스위치를 on/off한다.

#### 1. pwd(print working directoy)

- 지금 서 있는 곳을 출력해라

#### 2. ls(list)

#### cat, rm 명령어

| 명령어 | 기능 | 분류 |
| --- | --- | --- |
| cat | 파일 내용을 화면에 출력 (여러 파일 이어붙여 출력도 가능) | 파일/디렉토리 |
| rm | 파일 또는 디렉토리 삭제 | 파일/디렉토리 |

rm 명령어 주의사항

- 복구가 불가능하다.
    - Windows나 macOS의 휴지통 같은 안전장치가 없습니다. rm으로 지운 파일은 기본적으로 되돌릴 수 없다.
- rf 옵션은 특히 위험하다.
    - r(하위 폴더까지 재귀적으로)과 f(확인 없이 강제로)를 같이 쓰면, 경로를 잘못 입력했을 때 큰 피해로 이어질 수 있다.
        - 예시: rm -rf / → 시스템 전체 삭제 시도 (최신 리눅스에서는 기본적으로 막혀있지만, 과거엔 실제 사고 사례도 많다.)
        - 예시: rm -rf ./ 앞에 공백이나 오타 하나로 의도치 않은 상위 경로가 삭제될 수 있다.
- 와일드카드() 사용 시 신중해야 한다.
    - rm *.txt처럼 와일드카드를 쓸 때, 의도한 파일 패턴이 맞는지 먼저 ls *.txt로 확인해보는 습관이 안전하다.
- 경로 확인 습관화 해야 한다.
    - 삭제 전에 pwd로 현재 위치를 확인하고, ls로 대상 파일/폴더가 맞는지 한 번 더 점검하는 것이 좋다.
- 대안으로 안전장치 마련해야 한다.
    - rm -i → 삭제 전 하나하나 확인 메시지를 띄워준다.(실수 방지)
    - 중요한 작업 전에는 mv로 별도 백업 폴더에 옮겨두는 것도 방법이다.

#### 윈도우에서 리눅스 보는 법

- /mnt/c 로 들어간다.(c 드라이브가 그대로 보인다.)
- cd /mnt/c/Users(내 바탕화면까지 갈 수 있다.)

#### 리눅스에서 윈도우 보는 법

- 파일 탐색기의 주소창에 \\wsl$를 입력한다.
- Ubuntu 폴더가 나온다.
