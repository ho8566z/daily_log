# Notion 포트폴리오 항목별 아이콘

Chrome에서 [Lucide](https://lucide.dev/icons/) 아이콘 세트를 확인해 고른 목록입니다. 아이콘 이름마다 SVG 주소가 실제로 열리는 것을 확인했습니다. (lucide-static 0.468.0, ISC 라이선스, 상업·개인 사용 가능)

각 아이콘의 상세 페이지: `https://lucide.dev/icons/<아이콘 이름>`

## Notion에서 쓰는 방법
1. 페이지나 콜아웃의 아이콘을 클릭합니다.
2. **Custom** 탭에서 이 아이콘의 SVG(또는 PNG로 변환한 파일)를 업로드합니다.
3. Notion 기본 아이콘 탭에서 같은 이름으로 검색해 비슷한 모양을 고를 수도 있습니다.
