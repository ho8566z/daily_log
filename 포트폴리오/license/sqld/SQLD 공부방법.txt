SQLD

[ 1단계 : 데이터 모델링 먼저 잡기 (약 5~7일) ]
(여기서 과락이 많이 나옵니다.)

+ 반드시 이해해야 할 것
- 엔터티 / 속성 / 식별자
- 기본키(PK) / 외래키(FK)
- 정규화 (1~3정규형)
- 관계 차수(1:1, 1:N, N:M)
- 식별관계 / 비식별관계

+ 공부법
- ERD를 직접 그려보기
- “왜 이렇게 설계하는가?”를 이해 중심으로 학습
(암기만 하면 문제 변형에 취약합니다.)

[ 2단계 : SQL 문법 정리 (약 7~10일) ]
(여기서 점수 차이가 납니다.)

+ 반드시 숙달할 것
- SELECT 실행 순서
- JOIN (INNER / OUTER)
- GROUP BY + HAVING
- 서브쿼리
- 집계함수
- 윈도우 함수 (RANK, ROW_NUMBER)

+ 특히 자주 틀리는 부분:
- WHERE vs HAVING 차이
- NULL 처리
- OUTER JOIN 조건 위치

+ 공부법
- 손으로 쿼리 써보기
- 결과값을 직접 예상해보기
- 실행 순서를 말로 설명해보기

[ 3단계 : 기출 반복 (최소 5회 이상) ]
(SQLD는 기출 패턴 반복형 시험입니다.)

+ 공부 방법:
- 최신 기출부터 풀기
- 틀린 문제 유형 분류
   - 계산 실수
   - 개념 부족
   - 문제 해석 실수

+ 점수 안정권 만들기
(기출 평균 75점 이상 나오면 합격권)
