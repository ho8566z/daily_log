public class MainClass {
	
	public static void main(String[] args) {

		 * 아버지의 중식당 - 메뉴 짬뽕, 짜장면

		FatherRestaurant fatherRestaurant = new FatherRestaurant();
		fatherRestaurant.makeJajangmyeon();		// 짜장면
		fatherRestaurant.makeJjamppong(); 		// 짬뽕
		
		/*
		 * 아버지의 은퇴, 자식에게 중식당을 물려준다.
		 * 중식당을 새로 오픈
		 */
		ChildResturant childResturant = new ChildResturant();
		childResturant.makeJajangmyeon();		// 짜장면
		childResturant.makeJjamppong();			// 짬뽕
		
		fatherRestaurant.makeBokkeumbap();		// 볶음밥
		childResturant.makeBokkeumbap();		// 볶음밥
		
		/*
		 * 아버지의 볶음밥이 맛 없는 자식
		 * 오버라이드(Override, 재정의)
		 */
		childResturant.makeBokkeumbap(2);
		
		/*
		 * 자식의 중식당에서 아버지 중식당의 단골손님왈, 아버지의 볶음밥을 먹고싶다고 말한다.
		 */
		childResturant.makeBokkeumbap(1);
		
	}

}

####산업 표준화

여러 회사나 제품이 공통된 규칙과 규격을 사용하도록 정하는 것이다.


####인터페이스

-> 인터페이스를 "산업 표준화"라는 비유를 사용하는 이유는, 인터페이스가 구현 클래스들이 따라야 할 공통 규격을 제공하기 때문이다.

Strategy Pattern(전략 패턴)이란?

Strategy Pattern은 하나의 작업을 수행하는 여러 가지 방법(전략)을 각각의 클래스로 분리하고, 상황에 따라 원하는 전략을 선택하여 사용하는 디자인 패턴이다.

-> 같은 일을 하는 여러 방법을 인터페이스로 묶고, 필요한 방법을 선택해서 사용하는 것이다.

------------------------------------------------------------------------

		 Strategy
		인터페이스
			│
   ┌────────┼────────┐
   ↓        ↓        ↓
StrategyA StrategyB StrategyC
 전략 A     전략 B     전략 C
 
 
 PaymentStrategy
      │
 ┌────┼─────────┐
 ↓    ↓         ↓
카드  현금    카카오페이

------------------------------------------------------------------------

핵심 3가지
1. 인터페이스
	→ 여러 전략이 지켜야 할 공통 규격
2. 전략 클래스
	→ 실제 작업 방법을 각각 구현
3. 전략 교체
	→ new CardPayment() → new CashPayment()처럼 원하는 전략을 선택

##디펜던시 인젝션

####Dependency Injection(DI, 의존성 주입)이란?

객체가 필요한 다른 객체(의존 객체)를 직접 생성하지 않고, 외부에서 전달받는 것이다.

1. 일반적인 방식 — 직접 생성

2. Dependency Injection — 외부에서 주입
즉,객체 간 결합도를 낮추고, 코드의 변경·확장·테스트를 쉽게 만들기 위해 사용한다.

------------------------------------------------------------------------

##싱글턴 패턴

특정 클래스의 객체가 프로그램 전체에서 단 하나만 생성되도록 보장하고, 그 하나의 객체를 어디서든 사용할 수 있도록 하는 디자인 패턴이다.

핵심 특징 3가지

1. 객체를 하나만 생성
	여러 번 객체를 요청해도 동일한 객체를 사용한다.

2. 외부에서 new로 객체를 직접 생성하지 못하게 함
	생성자를 private으로 만들어 외부에서 객체를 생성하지 못하도록 한다.

3. 하나의 객체를 공유
	getInstance() 같은 메서드를 통해 이미 만들어진 하나의 객체를 반환한다.
	
	
 Singleton

	 ▼

싱글턴 패턴 코드 예시

class Singleton {

    // ① 하나의 객체를 저장
    private static Singleton instance;

    // ② 외부에서 new 하지 못하도록 생성자를 private
    private Singleton() {
    }

    // ③ 객체를 하나만 생성하고 반환
    public static Singleton getInstance() {

        if (instance == null) {
            instance = new Singleton();
        }

        return instance;
    }
}


사용

public class Main {

    public static void main(String[] args) {

        Singleton obj1 = Singleton.getInstance();
        Singleton obj2 = Singleton.getInstance();

        System.out.println(obj1 == obj2);
    }
}

[ Singleton ]

package com.office.ex;

public class Singleton {
	
	private static Singleton singleton;
	private int count = 0;
	
	private Singleton() {}
	
	public static Singleton getInstance() {
		if (singleton == null) {
			singleton = new Singleton();
		}
		return singleton;
	}
	
	
	
	public void inceaseCount() {
		count++;
	}

	
	public int getCount() {
		return count;
	}

	
}
