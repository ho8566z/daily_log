## 리눅스에서 권한 확인

#### ls -l 명령 입력

!image.png

```smalltalk
rwx r-x r-x
│ │ │ │
│ │ │ └─ 기타 사용자(others)
│ │ └───── 그룹(group)
│ └───────── 소유자(user)
└──────────── 파일 종류
```

| 위치 | 의미 |
| --- | --- |
| 1번째 문자 | 파일 종류 |
| 2~4번째 | 소유자 권한 |
| 5~7번째 | 그룹 권한 |
| 8~10번째 | 기타 사용자 권한 |

```smalltalk
rwxr-xr-x
│
├─ - : 파일
├─ rwx : 소유자
├─ r-x : 그룹
└─ r-x : 기타 사용자
```

| 해당 문자(권한) | 의미 | 설명 |
| --- | --- | --- |
| - | 일반 파일 | 첫 번째 자리에 있을 때 일반 파일을 의미 |
| r | Read → 읽기 | 읽기 권한 |
| w | Write → 쓰기 | 쓰기 권한 |
| x | Execute → 실행 | 실행 권한 |
| - | 해당 권한 없음 | 권한 자리에 있을 때 해당 권한이 없음을 의미 |

```smalltalk
drwxr-xr-x
│ │   │   │
│ │   │   └─ 기타 사용자(Other) : 읽기 / 실행
│ │   └───── 그룹(Group)       : 읽기 / 실행
│ └───────── 소유자(User)      : 읽기 / 쓰기 / 실행
└─────────── 디렉터리
```

| 해당 문자(권한) | 의미 | 설명 |
| --- | --- | --- |
| d | Directory → 디렉터리 | 디렉터리임을 나타낸다. |
| - | 일반 파일 / 권한 없음 | 첫 번째 자리: 일반 파일을 나타낸다.
권한 자리: 해당 권한이 없음을 나타낸다. |
| r | Read → 읽기 | 읽기 권한 |
| w | Write → 쓰기 | 쓰기 권한 |
| x | Execute → 실행 | 실행 권한 |

#### 소유자와 소유 그룹 변경

|  | 명령어 | 사용법 | 사용 예시 | 설명 |
| --- | --- | --- | --- | --- |
| 소유자 변경 | chown | sudo chown 사용자 파일명 | sudo chown kim hello.sh | hello.sh의 소유자를 kim으로 변경한다. |
| 소유 그룹 변경 | chgrp | sudo chgrp 그룹명 파일명 | sudo chgrp developers hello.sh | hello.sh의 그룹을 developers로 변경한다. |
| 한 번에 변경 | chown | sudo chown 사용자:그룹 파일명 | sudo chown kim:developers hello.sh | -rwxr-xr-x 1 kim developers 21 Sep 15 15:02 hello.sh |
| 디렉터리까지 변경 | -R
(하위 파일과 디렉터리까지 전부 변경하려면 R을 사용한다.) | sudo chown -R 사용자:그룹 파일명 | sudo chown -R kim:developers test | `R` = Recursive → 해당 디렉터리와 그 안의 모든 항목에 적용 |

## sudo 란?

- 리눅스에서 관리자 권한으로 실행하도록 하는 명령어이다.

| os | 관리자 권한 실행 방법 | 실행 예시 |
| --- | --- | --- |
| 원도우 | 창을 열 때, 관리자로 연다. | 우클릭 → 관리자 권한으로 실행 |
| 리눅스 | 명령 앞에 sudo를 입력한다. | sudo apt update |

---

#### sudo 비밀번호 생략 (NOPASSWD 설정)

- 목적은 sudo 사용 시 비밀번호를 묻지 않도록 하는 것이다.

```powershell
sudo visudo
```

```powershell
사용자이름 ALL=(ALL) NOPASSWD: ALL
```

- 파일 맨 아래에 추가 이후, 저장 후 종료하고, sudo 입력해도 비밀번호를 묻지 않는다.

---

#### sudo 비밀번호 재요구 (원상 복구)

- 목적은 다시 비밀번호를 물어보도록 되돌리는 것이다.

```bash
sudo visudo
```

```
사용자이름 ALL=(ALL) PASSWD: ALL
```

- 아까 추가한 줄을 찾아서, 삭제하거나 NOPASSWD → PASSWD로 변경한다.
- 저장 후 종료하고, 즉시 비밀번호의 재요구를 적용해야 한다.

---

| 구분 | NOPASSWD | PASSWD(기본값) |
| --- | --- | --- |
| sudo 실행 시 | 비밀번호 안 물어봄 | 비밀번호 물어봄 |
| 보안 | 낮음(권한 탈취 위험) | 높음(권장) |
| 사용 예시 | 개인 VM, 자동화 스크립트 | 다중 사용자 시스템, 일반 서버 |

---

#### sudo 사용할 때, 주의사항

- 관리자 권한은 안전장치를 끄는 것이다.

| 상황 | 이유 | 규칙 |
| --- | --- | --- |
| 인ㅌ터넷에서 복사한 명령에 sudo | 무엇을 하는지 모른 채 관리자로 돈다. | 무엇을 하는 명령인자 확인하기 |
| sudo rm -rf 계열 | 되돌릴 수 없다. 시스템이 날아간다. | 사용 금지 |
| 안 되니깐 일단 sudo | 원인을 안 보고 덮는다. | 먼저 메세지를 읽는다. |
| 설치 명령(apt install) | 시스템 폴더에 써야 한다. | 며기는 필요하다. |

---

#### 추가 명령어

| 명령 | 언제 쓰는지 | 안 쓴다면 |
| --- | --- | --- |
| ls -l | 권한이 궁금할 때 | 왜 안되는지 모른다. |
| chmod +x | 실행이 거부될 때 | gradlew에서 막힌다. |
| sudo | 설치하거나 시스템을 설정할 때 | Permission denied |
| ./파일 | 지금 자리의 것을 실행 | command not found |

#### 윈도우와 리눅스에서 프로그램 설치하는 방법

- 먼저  sudo apt update를 통해 새로운 버전으로 업데이트 한다.

| os | 설치 방법 | 삭제 방법 | 비고 |
| --- | --- | --- | --- |
| 윈도우 | 사이트를 찾고, 설치 파일을 다운 받는다. | 제어판을 열어 지운다. |  |
| 리눅스 | sudo apt install 프로그램 이름 | sudo apt remove 프로그램 이름 | 사이트를 찾을 필요가 없다. |

#### 프로그램 조회 및 삭제 명령

| 상황 | 명령어 | 설명 |
| --- | --- | --- |
| 조회 | apt list --installed | grep tree | 시스템에 tree 패키지가 설치돼 있는지 여부를 알려준다. |
| 삭제 | sudo apt install 파일이름 | 프로그램만 지운다, 설정은 남는다. |
| 완전 삭제 | sudo apt remove —purge 파일이름 | 설정까지 통째로 지운다. |

#### apt list --installed | grep tree

| apt list --installed | 시스템에 설치된 모든 패키지 목록을 출력 |
| --- | --- |
| | | 그 출력을 다음 명령어로 전달 |
| grep tree | 그중 이름에 "tree"라는 문자열이 포함된 줄만 필터링 |

---

#### apt 명령 정리

| 명령 | 하는 일 | 언제 사용하는지 |
| --- | --- | --- |
| sudo apt update | 창고 목록을 새로 받는다. | 프로그램 설치 전에 한번 |
| sudo apt install 파일 | 창고에서 꺼낸다. | 새 프로그램 설치 |
| sudo apt remove 파일 | 지운다. | 프로그램을 사용하지 않게 되면 |
| apt list —installed | 깔린 것 목록 | 프로그램 목록을 확일할 때 |
| q / Ctrl +C | 빠져나온다. | 자주 사용한다. |

---

#### 핵심

| 증상 | 원인 | 해결 |
| --- | --- | --- |
| Unable to locate package | 창고 목록이 낡았다. | ‘sudo apt update’ 먼저 |
| 그래도 못 찾는다. | 그 저장소가 꺼져 있다. | -- universe를 켠다. |
| Permission denied | sudo를 안 붙였다. | 앞에 sudo를 붙인다. |
| 비밀번호가 입력되지 않는다. | 정상이다. | 그냥 입력하고, Enter |
| Could not get lock | 다른 apt가 돌고 있다. | 일정 시간(1분)을 기다렸다가 다시 |
| 화면에서 못 빠져나온다. | -- | ‘q’가 안되면, ‘Ctrl + C’ |
