## 도커 컴포즈(Docker Compose) 란?

- 여러 개의 컨테이너로 구성된 애플리케이션을 하나의 설정 파일로 정의하고, 여러 컨테이너를 한 번에 생성, 실행, 관리할 수 있게 해주는 도구이다.

| Docker | 컨테이너 하나하나를 관리 |
| --- | --- |
| Docker Compose | 여러 컨테이너를 하나의 묶음으로 관리 |
- docker-compose.yml에 각 컨테이너의 이미지, 포트, 환경변수, 네트워크, 볼륨 등을 설정해 놓고 한 번에 실행할 수 있다.

!image.png

#### Docker 명령을 여러 개를 입력하면 달라진다.

| 명령을 실행할 때의 위험 요소 | 위험 설명 |  |
| --- | --- | --- |
| 순서 문제 | MySQL을 먼저 실행해야 하는 등 실행 순서를 직접 신경 써야 한다. |  |
| 설정 불일치 | 사람마다 포트, 환경변수, 네트워크 등의 설정이 달라질 수 있다. |  |
| 재현성 부족 | 다른 컴퓨터에서 동일한 환경을 다시 만들기 어려울 수 있다. |  |
| 오타 위험 | 긴 명령어를 직접 입력하면서 옵션이나 환경변수를 잘못 입력할 수 있다. |  |
| 관리 어려움 | 컨테이너가 많아질수록 실행 명령이 복잡해진다. |  |

!image.png

#### docker-compose up -d --build 란?

- Docker Compose로 컨테이너를 빌드하고 백그라운드에서 실행하는 명령어이다.

```
docker-compose up-d--build
```

| 부분 | 의미 |  |
| --- | --- | --- |
| docker-compose | Docker Compose를 사용한다. |  |
| up | docker-compose.yml에 정의된 서비스를 생성, 실행한다. |  |
| -d | 백그라운드에서 실행한다.(Detached) |  |
| --build | 컨테이너를 실행하기 전에 이미지를 다시 빌드한다. |  |
