## Spring Boot + JPA — Entity 필드 추가 시 nullable 설계

#### [ entity/User ]

```java
// nullable — 이미 가입한 회원도 재부팅 시 값 없이 재생성된다.
@Column(length = 20)
private String phone;
```

#### [ model/UserRequest ]

```java
// 필수 아님, — 안 보내면 그냥 null 로 저장된다. 보낼 땐 010-1234-5678 형식만 통과.
@Pattern(regexp = "^01[0-9]-\\d{3,4}-\\d{4}$", message = "전화번호는 010-1234-5678 형식입니다")
private String phone;
```

#### 새 컬럼 추가 시 nullable 허용

- 기존 회원 데이터가 있는 상태에서 컬럼을 새로 추가하면, 기존 row는 값이 없으므로 NOT NULL 제약을 걸면 마이그레이션이 깨진다.
- 따라서 신규 컬럼은 기본적으로 nullable로 열어두고, 필요 시 백필 후 제약을 건다.
    - ‘백필(backfill)’은 이미 저장돼 있는 기존 row들의 빈 값을 나중에 채워 넣는 작업을 말한다.

## Hibernate 란?

- JPA(Java Persistence API)는 명세(interface)일 뿐이고, Hibernate는 그 명세를 구현한 실제 구현체(implementation)다.
    - JPA는 "자바 객체와 DB 테이블을 어떻게 매핑할지"에 대한 표준 규약(어노테이션, 인터페이스 등)만 정의했기 때문에 실제 동작 코드는 없다.
    - Hibernate는 JPA 명세를 따르면서, 실제로 SQL을 생성하고 DB와 통신하는 라이브러리이다.

#### Hibernate가 실제로 하는 일

- Entity 객체 ↔ DB 테이블 자동 매핑
- 영속성 컨텍스트(1차 캐시) 관리
- 변경 감지(Dirty Checking) → SQL 자동 생성
- 지연 로딩(Lazy Loading) 처리
- 트랜잭션 관리 지원

## DDL (Data Definition Language) 이란?

- 데이터베이스 구조(스키마)를 정의하는 언어로서 테이블, 컬럼, 제약조건 등을 만들고 바꾸고 지운다.

| 명령어 | 역할 |
| --- | --- |
| CREATE | 테이블/DB 등 생성 |
| ALTER | 테이블 구조 변경 (컬럼 추가/수정/삭제) |
| DROP | 테이블/DB 삭제 |
| TRUNCATE | 테이블 데이터 전체 삭제(구조는 유지) |

## DML (Data Manipulation Language) 이란?

- 데이터를 다루는 언어로서 테이블 구조는 그대로 두고, 그 안의 데이터를 읽고 쓰고 고치고 지운다.

| 명령어 | 역할 |
| --- | --- |
| SELECT | 데이터 조회 |
| INSERT | 데이터 삽입 |
| UPDATE | 데이터 수정 |
| DELETE | 데이터 삭제 |

## 크롤링(Crawling) 이란?

- 웹사이트를 자동으로 돌아다니며 페이지의 정보를 수집하는 작업을 말한다.

#### **기본 개념**

- 이 작업을 수행하는 프로그램을 크롤러(Crawler) 또는 스파이더(Spider), 봇(Bot)이라고 부른다.
- 웹 페이지에 접속해서 HTML을 읽고, 그 안의 링크를 따라 다음 페이지로 계속 이동하며 정보를 모으는 방식이다.

#### **작동 순서 (일반적인 흐름)**

1. 시작 URL에 접속한다.
2. 페이지의 HTML을 가져온다.
3. 필요한 데이터를 추출(파싱)한다.
4. 페이지 안의 다른 링크들을 찾아 다음 방문 목록에 추가한다.
5. 이 과정을 반복하며 사이트를 넓게 탐색한다.

#### **대표적인 활용 예**

- 구글, 네이버 같은 검색엔진이 웹 전체를 색인(index)하기 위해 사용한다.
- 가격 비교 사이트가 여러 쇼핑몰의 상품 가격을 모을 때 사용한다.
- 데이터 분석/연구를 위해 뉴스 기사나 게시글을 수집할 때 사용한다.

#### **크롤링 vs 스크래핑, 헷갈리기 쉬운 개념**

- 크롤링은 여러 페이지를 돌아다니며 링크를 따라가는 "탐색" 자체에 초점을 맞춘다.
- 스크래핑(Scraping)은 특정 페이지에서 원하는 데이터를 "추출"하는 데 초점을 맞춘다.
- 실제로는 두 개념이 함께 쓰이는 경우가 많다.

#### **주의할 점**

- 사이트의 robots.txt 규칙을 확인하고 존중해야 한다.(크롤링 허용/금지 범위 명시)
- 과도한 요청은 서버에 부담을 주고, 법적/윤리적 문제로 이어질 수 있다.
- 로그인/개인정보가 필요한 페이지는 함부로 크롤링하면 안 된다.
