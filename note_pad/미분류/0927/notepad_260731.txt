[ javascript > interval ]

interval: 일정한 시간 간격(밀리초 단위)마다 지정한 함수를 반복해서 실행하는 동작

1. 핵심 메서드: setInterval()
-원하는 동작을 주기적으로 실행할 때 setInterval() 함수를 사용한다.

const 함수명 = setInterval(function, delay);

	-function: 주기적으로 실행할 콜백 함수
	-delay: 실행 간격 (밀리초 단위, 1000ms = 1초)
	-반환값: 실행 중인 타이머를 식별할 수 있는 고유한 타이머 ID

ex)
	let count = 1;

	// 1000ms(1초)마다 anonymous 함수를 실행
	const intervalId = setInterval(() => {
	  console.log(`${count}초가 지났습니다.`);
	  count++;
	}, 1000);

##---------------------------------------------###
	
2. 반복 멈추기: clearInterval()
-setInterval()은 멈추라고 명령하지 않으면 페이지가 닫힐 때까지 무한히 반복된다. 
-반복을 종료하려면 clearInterval()에 타이머 ID를 전달해야 한다.

ex)
	let count = 1;

	const timerId = setInterval(() => {
	  console.log(`카운트: ${count}`);
	  
	  if (count === 5) {
		clearInterval(timerId); // count가 5가 되면 반복 중단
		console.log("타이머가 종료되었습니다.");
	  }
	  
	  count++;
	}, 1000);
	
##---------------------------------------------###

# 오차 누적 (Time Drift)

브라우저의 메인 스레드가 바쁘거나 다른 복잡한 작업을 수행 중이면 타이머 실행이 밀린다. 
이 밀림 현상(Drift)이 시간이 지나면서 누적되어 실제 시계의 1초와 차이가 벌어지게 된다.

let count = 0;

setInterval(function() {
	count++;
	console.log('count: ', count);

}, 1000);
