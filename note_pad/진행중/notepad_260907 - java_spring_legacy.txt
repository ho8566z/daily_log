HandlerInterceptor 란?

Spring MVC에서 Controller가 실행되기 전·후에 특정 작업을 수행할 수 있도록 해주는 인터셉터(Interceptor)이다.

즉, Controller의 요청 처리 과정에 개입하여 공통 작업을 수행하는 기능이다.


| 메서드                 | 실행 시점           | 주요 용도             |
| ------------------- | --------------- | ----------------- |
| preHandle()       | Controller 실행 전 | 로그인 확인, 권한 확인 등   |
| postHandle()      | Controller 실행 후 | ModelAndView 수정 등 |
| afterCompletion() | 요청 처리 완료 후      | 로그 기록, 자원 정리 등    |


	preHandle 이란?
	
	Controller가 실행되기 전에 호출되는 메서드이다.
	
	로그인 여부를 검사하는 경우, 로그인되어 있으면 Controller로 진행하고, 로그인되어 있지 않으면 Controller를 실행하지 않고 로그인 페이지로 이동한다.


	postHandle 이란?
	
	Controller의 요청 처리가 끝난 후, View가 실행되기 전에 호출되는 HandlerInterceptor의 메서드이다.
	
	Controller가 처리한 결과인 ModelAndView를 확인하거나 수정하는 작업 등에 사용할 수 있다.
	
	
	afterCompletion 이란?
	
	Controller의 실행과 View 처리까지 모두 끝난 후 호출되는 HandlerInterceptor의 메서드이다.
	
	요청 처리가 완전히 끝난 후 정리 작업을 수행할 때 사용한다.

DATE_FORMAT() 이란?


MySQL에서 날짜·시간 데이터를 지정한 형식의 문자열로 변환하는 함수이다.

DB에서 데이터를 조회할 때 SQL문에서 날짜·시간 데이터의 표시 형식을 가공할 수 있다.



동적 SQL과 날짜 형식 변환의 관계

동적 SQL 자체가 아니라 SQL에서 데이터를 가공하는 것이다.

DB에서 데이터를 가져올떄, Dao의 sql문에서 데이터를 가공하는 쿼리문

String sql =
    "SELECT DATE_FORMAT(reg_date, '%Y년%m월%d일 %H시%i분%s초') " +
    "FROM tbl_book";

2026-09-07 15:45:30 -> 2026년09월07일 15시45분30초

동적 SQL(Dynamic SQL) 이란?

프로그램의 실행 조건이나 입력값에 따라 SQL문을 동적으로 구성하여 실행하는 방식이다.

즉, 항상 동일한 SQL문을 실행하는 것이 아니라 조건에 따라 WHERE, ORDER BY, 조회 컬럼, 정렬 방식 등을 변경할 수 있다.
