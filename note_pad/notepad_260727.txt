# HTML과 CSS를 분리해서 사용하는 이유

1. 다양한 기기와 환경 대응 (PC, 모바일, 다크모드 등)
하나의 HTML, N개의 화면: HTML로 내용과 구조를 한 번만 작성해 두면, 화면 크기(PC, 태블릿, 모바일)나 사용자 환경(라이트/다크 모드)에 따라 CSS만 다르게 적용하여 최적화된 화면을 보여줄 수 있다.
	유연한 반응형 웹: 디자인이 분리되어 있기에 미디어 쿼리(Media Query) 등을 활용해 기기별로 레이아웃을 손쉽게 재배치할 수 있다.

2. 유지보수와 수정의 편의성
일괄 변경: 수백 개 페이지의 디자인이나 색상을 바꿔야 할 때, 각 HTML을 수정할 필요 없이 외부 CSS 파일 하나만 수정하면 웹사이트 전체에 즉시 반영된다.
	작업의 독립성: 글 내용을 고칠 때는 HTML만, 배치나 스타일을 고칠 때는 CSS만 건드리므로 서로의 코드를 꼬이게 만들 위험이 줄어든다.

3. 코드 재사용성과 개발 생산성
스타일 재사용: 공통 버튼, 폰트, 헤더 디자인 등을 CSS 파일로 정의해 두면 여러 HTML 페이지에서 그대로 가져와 쓸 수 있다.
	분업 용이: 기획자/개발자가 HTML 구조를 짜는 동안, 디자이너/퍼블리셔가 CSS 스타일 작업을 동시에 진행할 수 있다.

4. 성능 향상, 검색 엔진 최적화(SEO), 웹 접근성
로딩 속도 향상: 브라우저는 한 번 다운로드한 CSS 파일을 저장(캐싱)해 두기 때문에, 다른 페이지로 이동해도 매번 스타일을 새로 받지 않아 속도가 빨라진다.
	SEO 및 접근성: HTML에 불필요한 디자인 코드가 섞여 있지 않고 순수한 '정보'만 깔끔하게 남아 있어, 구글/네이버 같은 검색 로봇이 내용을 쉽게 이해하고 스크린 리더(시각장애인용)도 정확하게 읽을 수 있다.

# Ellipsis

- 메일등의 제목이 길어서 '...'으로 표시되는 것
(‘말줄임표’ 또는 ‘말줄임 처리’라고 부르며, 웹/앱 개발이나 디자인 분야에서는 영문 용어로 ‘텍스트 오버플로우(Text Overflow)’ 또는 ‘줄임표(Ellipsis)’ 처리라고 부른다.)

1. 한 줄 말줄임 처리 (가장 흔한 방식)
	메일 목록처럼 제목이 한 줄을 넘어갈 때 ...으로 줄이는 기본 CSS 속성입니다.

--------------------------------------------------------------------------------
CSS
.email-title {
  width: 300px;           /* 너비 지정 */
  white-space: nowrap;    /* 줄바꿈을 하지 않음 */
  overflow: hidden;       /* 영역을 벗어나는 글자는 숨김 */
  text-overflow: ellipsis;/* 벗어나는 글자를 '...'으로 표시 */
}
white-space: nowrap;: 텍스트가 아무리 길어도 다음 줄로 넘어가가지 않게 한 줄로 강제합니다.

overflow: hidden;: 설정한 너비(width)를 넘어가는 텍스트를 화면에 보이지 않게 잘라냅니다.

text-overflow: ellipsis;: 잘려 나간 부분의 끝에 자동으로 ...을 붙여줍니다.
--------------------------------------------------------------------------------

2. 여러 줄 말줄임 처리 (2줄 이상일 때)
	메일 본문 요약처럼 2줄이나 3줄까지 보여주고 그 이후부터 ... 처리를 하고 싶을 때는 아래와 같이 작성한다.

--------------------------------------------------------------------------------
CSS
.email-summary {
  width: 300px;
  overflow: hidden;
  text-overflow: ellipsis;
  
  display: -webkit-box;
  -webkit-line-clamp: 2; /* 보여줄 줄 수 (예: 2줄) */
  -webkit-box-orient: vertical;
}
--------------------------------------------------------------------------------
