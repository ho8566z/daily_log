MemberController에 있는 @WebServlet을 web.xml로 애너테이션?

->MemberController의 @WebServlet 애너테이션으로 설정하던 서블릿 매핑 정보를 web.xml에 직접 작성하는 방식


[ web.xml ]에 추가해야 @WebServlet와 같이 사용할 수 있다.

<servlet>
    <servlet-name>MemberController</servlet-name>
    <servlet-class>com.office.dbex.member.MemberController</servlet-class>
</servlet>

<servlet-mapping>
    <servlet-name>MemberController</servlet-name>
    <url-pattern>/member/*</url-pattern>
</servlet-mapping>


차이
방식					설정 위치				예
애너테이션 방식		Java 클래스			@WebServlet("/member/*")
web.xml 방식			XML 설정 파일			<servlet>, <servlet-mapping>


@WebServlet <-> web.xml의 <servlet> + <servlet-mapping>
