#### Docker 란?

- 애플리케이션을 실행하는 데 필요한 환경을 하나의 컨테이너로 묶어서, 어디서든 동일하게 실행할 수 있도록 해주는 컨테이너 플랫폼이다.
- Docker를 사용하면 필요한 환경을 이미지(Image) 로 만들어 두고, 그 이미지를 기반으로 컨테이너(Container) 를 실행할 수 있다.

#### DockerHub 란?

- Docker Image를 저장하고 공유할 수 있는 온라인 저장소(Registry)이다.

#### Docker와 DockerHub의 관계

| 구분 | 내용 |  |
| --- | --- | --- |
| **Docker** | 애플리케이션을 실행하는 데 필요한 환경의 묶음 |  |
| **DockerHub** | Docker Image를 저장하고 공유할 수 있는 공간 |  |

---

#### WAS(Web Application Server) 란?

- 웹 애플리케이션을 실행하고, 클라이언트의 요청을 받아 애플리케이션의 로직을 처리하는 서버이다.
- 서버 프로그램을 WAS라고 하며, Tomcat은 대표적인 WAS 중 하나이다.

#### L4장비 란?

- 네트워크의 4계층(Transport Layer) 정보를 기준으로 트래픽을 분산해 주는 장비이다.

```
                    사용자
                      │
                  HTTP 요청
                      ↓
                ┌──────────┐
                │ L4 장비  │
                │ 로드밸런서 │
                └────┬─────┘
                     │
             ┌───────┴───────┐
             ↓               ↓
        ┌─────────┐      ┌─────────┐
        │ Server 1│      │ Server 2│
        └─────────┘      └─────────┘
```

#### 왜 L4인가?

- OSI 7계층에서 L4 = 전송 계층(Transport Layer)이다.
- L4 장비는 주로 다음과 같은 정보를 이용한다.
    - IP 주소
    - TCP / UDP
    - Port 번호
- L4 장비가 요청을 여러 서버로 분산시키는 것을 로드 밸런싱(Load Balancing)이라고 한다.
