#### N:1 관계

- user_member의 authority_no와 user_authority의 no는 N:1 (다대일) 관계이다.
- 의미
    - 여러 개의 user_member(N) 가 하나의 user_authority(1) 를 참조할 수 있다.
    - 즉, 여러 회원이 같은 권한(예: "USER", "ADMIN")을 공유한다.

# Spring Security Framework

## Spring Security Framework 란?

- Java 기반 애플리케이션(특히 Spring 프레임워크 기반)에서 인증(Authentication)과 인가(Authorization)를 담당하는 보안 프레임워크이다.

#### 기존 로그인 방식의 한계

- 세션을 이용한 로그인 방식
    - 사용자가 로그인에 성공하면 서버가 해당 사용자의 정보를 서버 메모리(세션 저장소) 에 저장하고, 클라이언트에게는 그 정보를 식별할 수 있는 세션 ID만 쿠키로 전달하는 방식이다.
- 보안 취약점
    - 시스템, 애플리케이션, 네트워크 등에 존재하는 결함이나 허점으로, 공격자가 이를 악용해 시스템에 무단으로 접근하거나, 데이터를 탈취/변조하거나, 서비스를 마비시킬 수 있는 지점을 말한다.
    - 웹 애플리케이션의 대표적인 보안 취약점
        1.  SQL Injection (SQL 삽입)
            - 사용자 입력값을 제대로 검증하지 않아 악의적인 SQL 쿼리가 실행되는 취약점이다.
        
        2. XSS (Cross-Site Scripting)
        
        - 사용자 입력값에 스크립트를 삽입해서 다른 사용자 브라우저에서 실행시키는 공격이다.
        
        3. CSRF (Cross-Site Request Forgery)
        
        - 사용자가 로그인한 상태를 이용해, 본인도 모르게 의도치 않은 요청(비밀번호 변경, 송금 등)을 하게 만드는 공격이다.
        
        4. 인증/인가 취약점 (Broken Authentication/Authorization)
        
        - 비밀번호를 평문으로 저장한다.
        - 세션 관리가 미흡하다.(세션 고정 공격 등)
        - 권한 체크가 누락된다.(일반 유저가 /admin/**에 접근 가능)
        
        5. 민감 정보 노출
        
        - 비밀번호를 암호화 없이 DB에 저장한다.
        - 에러 메시지에 시스템 정보(스택 트레이스, DB 종류 등)를 그대로 노출한다.
- 유지보수의 어려움
    1.  보안 로직이 코드 전체에 흩어진다.(중복 코드)
    2.  새로운 페이지/기능 추가 시 매번 보안 코드 작성 필요하다.
        - 새 컨트롤러를 만들 때마다 "이 URL은 로그인 필요한가? 관리자만 접근 가능한가?"를 개발자가 매번 직접 판단해서 if문을 넣어야 한다.
    3.  비밀번호 암호화를 직접 관리해야 한다.
        - 회원가입, 비밀번호 변경, 로그인 검증 등 여러 곳에서 동일한 암호화 로직을 중복 작성한다.
        - 나중에 암호화 알고리즘을 바꾸려면(SHA-256 → BCrypt) 모든 사용처를 다 찾아서 수정해야 한다.
        - Salt 처리, 알고리즘 취약점 대응 등도 개발자가 직접 신경 써야 한다.
    4.  CSRF, 세션 고정 공격 등 방어 코드를 직접 만들고 유지해야 한다.
        - 프레임워크가 검증한 표준 방식이 아니라 개발자가 짠 로직이므로, 새로운 공격 기법이 나올 때마다 직접 대응 코드를 찾아서 패치해야 한다.
    5.  테스트/디버깅 범위가 넓어진다.
        - 로그인 로직 하나를 수정하면, 그 로직을 복붙해서 쓰는 모든 컨트롤러를 일일이 테스트해야 한다. Spring Security처럼 한 곳(SecurityConfig)에 모여있지 않으니 영향 범위 파악 자체가 어렵다.

#### Spring Security의 필요성

- 보안(Security)은 웹 애플리케이션의 필수 요소이다.
- Spring Boot에서 강력한 보안 프레임워크를 제공한다.
- 주요 기능
    - 개인정보 보호
    - 인증과 인가 기능 제공
    - 불법적인 접근 차단

## Spring Security의 주요 기능

#### 인증(Authentication)

- 사용자가 본인이 맞는지 신원을 검증하는 절차이다.
- 인증의 대표적인 방식
    
    
    | 방식 | 설명 |
    | --- | --- |
    | **지식 기반** | 아이디/비밀번호, PIN 번호 (내가 알고 있는 것) |
    | **소유 기반** | OTP, 인증서, 스마트폰 (내가 가지고 있는 것) |
    | **생체 기반** | 지문, 얼굴 인식 (내 몸 자체의 특징) |
    | **소셜 로그인** | 구글/네이버/카카오 계정으로 대신 인증 (OAuth2) |

#### 인가(Authorization)

- 인증(신원 확인)이 끝난 사용자가 특정 자원/기능에 접근할 권한이 있는지를 판단하는 절차이다.
- 핵심 개념: Role vs Authority
    
    
    | 구분 | 설명 | 예시 |
    | --- | --- | --- |
    | Role (역할) | 넓은 범위의 권한 묶음 | ROLE_USER, ROLE_ADMIN |
    | Authority (권한) | 좀 더 세밀한 단위 | READ_PRIVILEGE, WRITE_PRIVILEGE |

#### 자동 보안 설정

- Spring Boot가 spring-boot-starter-security 의존성만 추가해도, 개발자가 별도의 설정 없이 기본적인 보안 기능을 자동으로 적용해주는 기능이다.
- 의존성 추가만으로 발생하는 일
    1.  모든 요청에 인증 필요
    2.  기본 로그인 폼 자동 생성
    3.  기본 사용자 계정 자동 생성
    4.  CSRF 보호 자동 활성화
    5.  세션 고정 공격 방지 자동 적용
    6.  보안 관련 HTTP 헤더 자동 추가

package com.office.calendar.config;

import lombok.extern.slf4j.Slf4j;
import org.springframework.context.annotation.Bean;
import org.springframework.context.annotation.Configuration;
import org.springframework.security.config.annotation.web.builders.HttpSecurity;
import org.springframework.security.config.annotation.web.configuration.EnableWebSecurity;
import org.springframework.security.core.userdetails.User;
import org.springframework.security.crypto.bcrypt.BCryptPasswordEncoder;
import org.springframework.security.crypto.password.PasswordEncoder;
import org.springframework.security.web.SecurityFilterChain;

@Slf4j
@Configuration
@EnableWebSecurity
public class SecurityConfig {

@Bean PasswordEncoder passwordEncoder() {
    return new BCryptPasswordEncoder();

}

@Bean SecurityFilterChain filterChain(HttpSecurity http) throws Exception {

    http
            .cors(cors -> cors.disable())
            .csrf(csrf -> csrf.disable());

    http
            .authorizeHttpRequests(auth -> auth
                    .requestMatchers(
                            "/",
                            "/css/*",
                            "/img/*",
                            "/js/*",
                            "/member/signup",
                            "/member/signup_confirm",
                            "/member/signin",
                            "/member/signin_confirm",
                            "/member/findpassword",
                            "/member/findpassword_confirm")
                    .permitAll()
                    .anyRequest().authenticated());

    http
            .formLogin(login -> login
                    .loginPage("/member/signin")
                    .loginProcessingUrl("/member/signin_confirm")
                    .usernameParameter("id")
                    .passwordParameter("pw")
                    .successHandler((request, response, authentication) -> {
                        log.info("SIGNIN SUCCESS HANDLER()");

                        User user = (User) authentication.getPrincipal();
                        String targetURI = "/member/signin_result?loginedID=" + user.getUsername();
                        response.sendRedirect(targetURI);

                    })
                    .failureHandler((request, response, exception) -> {
                        log.info("SIGNIN FAIL HANDLER()");

                        String targetURI = "/member/signin_result";
                        response.sendRedirect(targetURI);

                    })
            );

    http
            .logout(logout -> logout
                    .logoutUrl("/member/signout_confirm")
                    .logoutSuccessHandler((request, response, authentication) -> {
                        log.info("SIGNOUT SUCCESS HANDLER()");

                        String targetURI = "/";
                        response.sendRedirect(targetURI);

                    }));

    return http.build();

}
}

import org.springframework.stereotype.Service;

import java.util.Optional;

@Slf4j
@Service
public class MemberDetailsService implements UserDetailsService {

final private MemberRepository memberRepository;

public MemberDetailsService(MemberRepository memberRepository) {
    this.memberRepository = memberRepository;
}

@Override
public UserDetails loadUserByUsername(String username) throws UsernameNotFoundException {
    log.info("[MemberDetailsService] loadUserByUsername()");

    Optional<MemberEntity> optionalMember = memberRepository.findByMemId(username);
    if (optionalMember.isPresent()) {
        MemberEntity findMemberEntity = optionalMember.get();
        return User.builder()
                .username(findMemberEntity.getMemId())
                .password(findMemberEntity.getMemPw())
                .roles(findMemberEntity.getAuthorityEntity().getAuthRoleName())
                .build();
    }

    return null;
}

package com.office.calendar.member.jpa;

import com.office.calendar.member.MemberDto;

import lombok.AllArgsConstructor;
import lombok.Builder;
import lombok.Data;
import lombok.NoArgsConstructor;

import java.time.LocalDateTime;
import java.time.format.DateTimeFormatter;

@Entity
@Table(name = "USER_MEMBER", uniqueConstraints = {@UniqueConstraint(columnNames = "ID")})
@Data
@NoArgsConstructor
@AllArgsConstructor
@Builder
public class MemberEntity {

@Id
@Column(name = "NO")
@GeneratedValue(strategy = GenerationType.IDENTITY)
private int memNo;

//    @Column(name = "ID", nullable = false, length = 20, unique = true)
@Column(name = "ID", nullable = false, length = 20)
private String memId;

@Column(name = "PW", nullable = false, length = 100)
private String memPw;

@Column(name = "MAIL", nullable = false, length = 20)
private String memMail;

@Column(name = "PHONE", nullable = false, length = 20)
private String memPhone;

/*
@Column(name = "AUTHORITY_NO")
private int memAuthorityNo;
 */

@ManyToOne
@JoinColumn(name = "AUTHORITY_NO")
private AuthorityEntity authorityEntity;

@Column(name = "REG_DATE", updatable = false)
private LocalDateTime memRegDate;

@Column(name = "MOD_DATE")
private LocalDateTime memModDate;

@PrePersist
protected void onCreate() {
//        this.memAuthorityNo = 1;
this.authorityEntity = new AuthorityEntity((byte) 1, "PRE_USER");
this.memRegDate = LocalDateTime.now();
this.memModDate = LocalDateTime.now();
}

@PreUpdate
protected void onUpdate() {
    this.memModDate = LocalDateTime.now();
}

public MemberDto toDto() {

    DateTimeFormatter formatter = DateTimeFormatter.ofPattern("yyyy-MM-dd HH:mm:ss");

    return MemberDto.builder()
            .no(memNo)
            .id(memId)
            .pw(memPw)
            .mail(memMail)
            .phone(memPhone)

.authorityDto(authorityEntity.toDto())

}
