Controller 코드
(Spring MVC에서 클라이언트의 요청을 받아 현재 서버 시간을 만들어 View(home.jsp)로 전달하는 과정)

사용자가 브라우저에서 "/"를 요청 -> Controller요청을 받아 해당하는 메서드를 실행 -> Model(n)을 통해 요청받은 데이터를 해당되는 .jsp의 파일이름을 반환 -> Spring이 [ 'prefix(= /WEB-INF/views/)' + .jsp(해당되는 jsp의 파일이름) + 'suffix(= .jsp)' ]으로 view를 만들어서 화면에 출력한다.

------------------------------------------------------------------------
Model(모델)
	-Controller에서 만든 데이터를 화면(View)으로 전달하기 위함
	<Controller가 View에게 데이터를 전달하는 것>


return "home" -> home.jsp
	-Spring의 ViewResolver가 연결시켜 준다.
	-return "home" -> ViewResolver -> /WEB-INF/views/ + home + .jsp -> /WEB-INF/views/home.jsp
	<View 이름은 home, 실제 JSP 파일을 찾아주는 것은 ViewResolver>
	

DispatcherServlet
	-맨 앞에서 요청을 받아 적절한 Controller에게 전달하는 역할
	<요청을 처리할 Controller를 찾는다.>
