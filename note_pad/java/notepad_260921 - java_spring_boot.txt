ResponseEntity 란?

Spring에서 HTTP 응답 전체(상태 코드, 헤더, 바디)를 세밀하게 제어할 수 있게 해주는 클래스입니다. 컨트롤러 메서드의 반환 타입으로 주로 사용됩니다.

주요 특징

HTTP 상태 코드를 직접 지정 가능 (200, 201, 404, 500 등)
응답 헤더를 커스텀으로 추가 가능
응답 바디에 원하는 데이터를 담을 수 있음


saveAndFlush 란?

Spring Data JPA의 JpaRepository가 제공하는 메서드로, 엔티티를 저장하면서 즉시 DB에 반영(flush)까지 수행합니다.

save()와의 차이

save(): 영속성 컨텍스트(1차 캐시)에 엔티티를 저장. 실제 DB에 쿼리가 나가는 시점은 트랜잭션이 커밋되거나 flush가 일어날 때(보통 트랜잭션 종료 시점)
saveAndFlush(): 저장과 동시에 즉시 flush()를 호출해서 바로 DB에 SQL을 실행시킴
