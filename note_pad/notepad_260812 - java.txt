##getter & setter

객체의 데이터를 안전하게 보존하기 위한 수단이다.

private으로 캡슐화한 필드에 접근할 수 있는 통로를 제공하는 것이다.


getter
	객체의 속성값을 읽어올때 사용하는 메서드

setter
	객체의 속성값을 설정할때 사용하는 메서드

##무결성

데이터베이스처럼 객체의 데이터(속성)가 외부로부터 훼손되지 않고 정확하며 신뢰가 보장되어야 한다는 것을 의미한다.

	무결성은 핵심적으로 데이터가 올바른 상태를 유지하는 것이다.


ex) 접근제어자 : private <- public으로 우회하는 방법

-1번째 사진 참조 : 이미지 만들기
-2번째 사진 참조 : 이미지 만들기

##객체 의존성(Object Dependencies)

한 객체가 다른 객체의 기능이나 데이터를 사용하면 의존 관계가 형성되며, 생성자를 통해 의존하는 인스턴스를 전달받아 내부에 할당하여 사용한다.

[ main, controller, system ]

------------------------------------------------------------------------
[ MainClass ]

package com.office.ex.main;

import com.office.ex.controller.CoolingController;
import com.office.ex.system.CoolingSystem;

public class MainClass {
	
	public static void main(String[] args) {
		
		CoolingSystem coolingSystem = 
				new CoolingSystem("white");
		
		CoolingController coolingController = 
				new CoolingController(coolingSystem);
		coolingController.control();
		
	}

}

package com.office.ex.system;

import java.time.LocalDateTime;
import java.time.format.DateTimeFormatter;

public class CoolingSystem {

	private int targetTemperature;		// 희망 온도(외부 접근 불가)

	private String color;				// 색상(외부 접근 불가)

		power = false;
		targetTemperature = 18;
		dateOfManufacture = getSystemDateTime();			// 현재시간

		return power;
	}

	public void setPower(boolean power) {

	}

		return targetTemperature;
	}

	public void setTargetTemperature(int targetTemperature) {
		
		if (!power) power = true;
		
		if (targetTemperature < 18) {
			targetTemperature = 18;
			
		} else if (targetTemperature > 30) {
			targetTemperature = 30;
		}
		
		this.targetTemperature = targetTemperature;

	// 현재 시스템 날짜, 시간 구하기 메서드
	private String getSystemDateTime() {
		
		LocalDateTime now = LocalDateTime.now();	// 현재 시스템의 날짜와 시간 구하기
		String dateTime = 
				now.format(DateTimeFormatter.ofPattern("yyyy-MM-dd HH:mm:ss"));
				// 날짜와 시간 현식을 맞춤
		
		return dateTime;
		
		// 3번째 사진 참조 : 이미지 만들기
		
	}

##메서드 오버로딩과 가변인자

####메서드 오버로딩

생성자 오버로딩과 비슷한 개념으로 하나의 메서드명으로 여러 개 선언하는 것을 의미한다.

동일한 이름의 메서드를 과적해서 선언한다는 의미이다.

매개변수 목록의 개수나 타입이 달라야 메서드 오버로딩이 가능하다.

[ overloadng }

------------------------------------------------------------------------
[ MainClass ]

[ TotalAverage ]

package com.office.ex.multiargs;

public class TotalAverage {
	
	// 총점 전문가 메서드
	static public int getTotalScore(int[] scores) {
		
		int totalScore = 0;
		for (int i = 0; i < scores.length; i++) {
			totalScore += scores[i];
		}
		return totalScore;
	}

	
	// 평균 전문가 메서드
	static public float getAverageScore(int[] scores) {
		
		float averageScore = 0.0f;
		if (scores.length > 0) {
			averageScore = getTotalScore(scores) / scores.length;
		}
		return averageScore;
	}

}
