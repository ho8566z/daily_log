AICE

[ 1단계: AI 전체 구조 잡기 (1~3일) ]

+ 먼저 이 개념들을 정확히 구분해야 합니다
- 인공지능(AI)
- 머신러닝(ML)
- 딥러닝(DL)
- 지도학습 / 비지도학습
- 분류 vs 회귀
- 빅데이터

+ 방법
- 유튜브에서 “AI 기초 강의”, “머신러닝 개념 설명” 검색
- 개념을 한 문장으로 정리해서 노트 작성

ex)
머신러닝 = 데이터를 통해 패턴을 학습하는 기술
딥러닝 = 인공신경망 기반의 머신러닝


[ 2단계: AICE 공식 교재 중심 학습 (5~7일) ]

+ AICE Basic은 기출과 유사한 개념 반복이 많습니다.
(공부 방법)
- 교재 1회 정독 (흐름 이해)
- 2회독 때는 핵심 단어 형광펜
- 오답노트 작성 (헷갈리는 개념 정리)

(특히 자주 나오는 영역)
- 지도학습 / 비지도학습 차이
- 과적합(Overfitting)
- 데이터 전처리
- AI 윤리 문제


[ 3단계: 문제풀이 중심 훈련 (3~5일) ]
- 모의고사 3회 이상 반복
- 틀린 문제 개념 다시 복습
- “왜 틀렸는지” 분석

+ 포인트
- AICE Basic은 “정의 + 사례 매칭형 문제”가 많습니다.

ex)
스팸메일 분류 → 분류 문제
주가 예측 → 회귀 문제
